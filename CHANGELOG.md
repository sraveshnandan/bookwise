# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2025-10-03

### Added
- Initial release of BookWise micro-reading app
- Core reading features: EPUB/PDF reader, audiobook player, summary viewer
- Authentication: email/password, Google, Apple Sign-In with onboarding
- Book discovery: search across Google Books, Open Library, Gutenberg, LibriVox
- Library management: progress tracking, highlights, bookmarks, wishlist
- Offline-first architecture: downloads, sync queue, background sync
- Subscriptions: RevenueCat integration with monthly/annual/lifetime plans
- Push notifications: reading reminders, new releases, achievements
- Platform features: iOS widgets, Android shortcuts, PWA support
- Comprehensive test suite: unit, integration, E2E tests

### Technical
- React Native + Expo Router + TypeScript
- Zustand state management with persistence
- TanStack Query for data fetching
- NativeWind + Tailwind CSS for styling
- React Native Reanimated for 60fps animations
- Supabase for auth, database, storage
- RevenueCat for subscriptions
- Expo ecosystem (notifications, file system, background tasks)
